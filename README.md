## 📖 소개

**MachineGE**는 체육관의 다양한 웨이트 장비들을 한 곳에서 쉽게 찾아볼 수 있는 iOS/macOS 앱입니다.

운동을 하다 보면 같은 부위를 자극하는 다양한 장비들이 있지만, 어떤 장비가 어떤 근육을 타겟으로 하는지, 비슷한 동작의 장비는 무엇인지 찾기 어려웠던 경험이 있으신가요? MachineGE가 그 고민을 해결해 드립니다!

---

## ✨ 주요 기능

| 기능 | 설명 |
|:---:|:---|
| 🌍 **국내외 장비 목록** | 국내 웨이트 장비와 해외 웨이트 장비를 한눈에 확인 |
| 🔄 **비슷한 궤적 찾기** | 동일한 운동 궤적을 가진 장비들을 쉽게 비교 |
| 💪 **주동근 운동 조회** | 타겟 근육별로 관련 장비와 운동을 한 페이지에서 확인 |
| 📱 **직관적인 UI** | SwiftUI로 구현된 깔끔하고 사용하기 쉬운 인터페이스 |

## 🛠 기술 스택

- **Language:** Swift 5.9+

## 🚀 시작하기

### 요구사항

- Xcode 15.0+
- iOS 17.0+ / macOS 14.0+

### 설치 방법

1. 레포지토리를 클론합니다:
   ```bash
   git clone https://github.com/837100/MachineGE.git
   ```

2. Xcode에서 프로젝트를 엽니다:
   ```bash
   cd MachineGE
   open MachineGE/MachineGE.xcodeproj
   ```

3. 시뮬레이터 또는 실제 기기에서 앱을 실행합니다.
